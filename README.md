# nanoql

nanoql is a stateless quantitative finance library for .NET. Every model and pricer is a plain function of its
inputs: there are no observers, lazy objects or global evaluation date, and market conventions are data, not code.

> **Status:** pre-release. Nothing is usable yet.

## Principles

- **Stateless in structure.** Inputs are immutable records; models, calibration and pricers are static functions.
  The same inputs always give the same outputs, and calls are safe to run in parallel.
- **Conventions as data.** Calendars, day counts, currencies, indexes and the instrument builders' defaults are XML
  records that a desk can read, override and version, so changing one is a data change, not a code change (see
  [docs/conventions.md](docs/conventions.md)).
- **Checked against its sources.** The core's results are checked against [QuantLib](https://www.quantlib.org/) 1.44,
  using test vectors generated by QuantLib's Python package and by QuantLib built from source; the extensions ported
  from QLNet are checked against QLNet 1.13.2. The vectors are committed to this repository, and what they cover is
  under [Validation](#validation).
- **Traceable to its sources.** Each ported file records the library, path and release it was ported from.
- **Python without .NET** (planned). Wheels generated over Native AOT: `pip install nanoql`, no .NET runtime needed.

## Validation

<!-- validation statement: written by tools/docs/validation-report.py -->
Checked against QuantLib 1.44 on Windows x64.

- **The vectors:** 3,348,122 reference outputs in 1,169 vector files, of which four files and 39,887 outputs check
  QLNet's additions against QLNet 1.13.2. Each output agrees within a relative 1e-10 of the larger of the two values and
  the output's scale (an amount's is its notional), except 4,854 (0.14%) held to a documented looser tolerance.
- **The tests:** QuantLib's own tests, ported at QuantLib's tolerances.
- **The types:** 2,281 of the 2,282 public types with executable code are run by a QuantLib-checked test, QLNet's
  additions by a QLNet-checked one. The one apart, `FactorReductionFunctions`, every output of which is QuantLib's
  defect fixed, is checked by its own tests. 303 more are listed apart, 291 with no executable code and 12 own-tested
  (six of them extensions, five experimental and one a term structure), and three are equality-only. 89.5% of the ported
  lines are covered.
- **The divergences:** 720 documented divergences from QuantLib, each with its own test class.
