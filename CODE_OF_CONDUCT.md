# Code of conduct

nanoql follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in all its community spaces: the repository, its issues, pull requests and discussions, and anywhere someone
represents the project.

Report unacceptable behaviour to conduct@nanoql.org. Reports reach the maintainers only and are kept confidential,
and the Covenant's enforcement guidelines apply.
